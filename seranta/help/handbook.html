Mengenal

Tentang Seranta

Seranta mengubah data survei vendor (HPDB dan KMZ) menjadi input desain otomatis yang siap dipakai, sekaligus memeriksa desain dengan 9 Standar Review Strand. Pekerjaan yang biasanya berjam-jam per cluster menjadi satu klik.

Empat alat: 1 siapkan input desain otomatis + QC survei, 2 pasca-desain (FDT FAT CODE, tabel closure), 3 estimasi alokasi FDT & FAT, 4 QC APD pasca-desain (34 kasus Handbook KMZ + 7 aturan paket APD). Hasilnya dipakai bersama lewat panel Navigator QC. Setiap angka punya dasar yang bisa ditelusuri (bagian Keandalan).

Arti nama

SERANTA = SERAt + NusaNTAra: serat optik yang menyambungkan seluruh Nusantara. Bunyinya dekat dengan sarana, karena Seranta adalah sarana bagi desainer untuk membangun jaringan yang rapi, cepat, dan benar sejak awal.

Huruf S dari satu helai serat

Satu garis tanpa putus: jaringan yang melentur mengikuti jalan dan kontur, tetapi tidak pernah patah.

Tiga titik

FDT → FAT → rumah pelanggan. Juga tiga langkah Seranta: siapkan, periksa, desain.

Cahaya di dalam serat

Warna berubah dari jingga ke biru muda: data yang mengalir sebagai cahaya dari sumber ke rumah.

Garis cakrawala

Laut Nusantara yang dilintasi jaringan, dari kota besar sampai pulau terluar.

Biru laut

Kedalaman, kepercayaan, kepulauan.

Cahaya serat

Teknologi, kecepatan, masa depan.

Jingga fajar

Era baru, energi, perubahan.

Pasang & update

Buka QGIS (3.22 LTR sampai 4.x) → menu Plugins → Manage and Install Plugins…
Pilih tab All, ketik Seranta di kotak pencarian.
Klik Install Plugin. Ikon Seranta muncul di toolbar dan menu Vector → Seranta.
Update: bila ada versi baru, QGIS memberi tahu dan plugin muncul di tab Upgradeable. Klik Upgrade Plugin.
Seranta dipasang dan diperbarui langsung dari repositori plugin resmi QGIS, jadi tidak perlu lagi memasang dari ZIP. Profil standar milik organisasi Anda disimpan di luar folder plugin (lihat Profil standar organisasi) sehingga tidak tertimpa saat update.

Siapkan data

Cukup dua folder. Nama file tidak perlu persis, cukup mengandung kata kunci yang dicetak tebal.

A. Folder cluster (satu folder per cluster)

3 ILIR RW 004\
├── HPDB_21116433298 3 ILIR RW 004_190HP_RPS.xlsx   ← wajib: tabel homepass (kolom LATITUDE & LONGITUDE)

Banyak cluster sekaligus? Taruh semua folder cluster di satu folder induk, lalu pilih folder induk itu (mode batch).

B. Folder data referensi (sekali saja, diingat Seranta)

QC\
├── ALL FUNNEL (EXISTING CITY).kmz                 ← boundary/funnel layanan + statusnya
├── DESIGN LITE ALL CITY 21-10-2026.kmz              ← jaringan existing: FDT, HP, tiang (untuk colo)

├── Compile Feeder.kmz                             ← opsional: jalur feeder
└── Config PROJECT 1X4.sdproj                       ← opsional: aturan proyek dari desain otomatis
Penting untuk pengguna baru: data referensi milik tim, tidak ikut di dalam plugin/ZIP. Tanpa file *FUNNEL*, Funnel tidak muncul dan standar 2 & 5 tidak dicek. Bagikan folder ini (mis. lewat drive bersama) ke setiap desainer. File boleh .kmz atau .kml dan boleh berada di subfolder. Bila isian 2 kosong, Seranta mencari otomatis folder referensi di sekitar folder cluster; hasilnya tertulis di kartu Data referensi pada ringkasan QC.
File harian boleh menumpuk (mis. Design Lite tanggal 20 dan 21). Seranta otomatis memakai tanggal terbaru dan menyimpan cache, sehingga run berikutnya jauh lebih cepat.

Membaca ringkasan QC

OK sesuai standar · CEK perlu diperbaiki atau ditanyakan ke vendor · -- data pembanding belum ada (isi folder referensi). Kartu paling atas menyebut berapa standar yang perlu dicek.

Sejak 3.3.0 setiap temuan juga punya tingkat: ERROR wajib diperbaiki atau disetujui pengecualian · WARNING perlu ditinjau · INFO petunjuk · UNVERIFIED data belum cukup (tidak dihitung lolos). Ringkasan juga memuat tabel Profil standar: setiap angka beserta dasar dan sumbernya.

Folder INPUT kini juga berisi HP.csv (Comma Delimited, nama kolom utuh) dan manifest_input.json. Manifest memuat jumlah fitur, CRS, SHA-256, pemetaan kolom, pemeriksaan siap impor (jumlah HP shp = csv = HPDB, ID unik berformat H00001, koordinat di Indonesia, ROADS tidak kosong) dan petunjuk setelan desain otomatis.

Cara membaca standar 7 (colo)

Contoh: PMS2-MYU01-H02: 284 m ke tiang cluster terdekat (kabel ke HP terjauh ±791 m); sisa 8 splitter; HP di FDT 104+0+91=195 dari 384. Artinya FDT berjarak 284 m garis lurus dari tiang cluster terdekat; bila kabel ditarik lewat jalur cluster sampai HP terjauh panjangnya kira-kira 791 m; FDT sudah melayani 104 HP, belum ada pesanan cluster lain, ditambah 91 HP cluster ini menjadi 195 dari kapasitas 384 HP.

Aturan tiang tambahan

Tinggi kabel di tengah bentang dihitung dari tinggi tiang dikurangi kedalaman tanam (10% + 0,6 m) dan lendutan 2 % bentang (spesifikasi teknis FTTH operator nasional); bila < 5,0 m di atas jalan menjadi info (Permen PU 20/PRT/M/2010 Ps. 12, status berlaku). Tiang 7 m pada bentang 50 m hanya memberi ±4,4 m, jadi crossing jalan raya memakai tiang 9 m (±6,2 m; praktik operator, RKS Diskominfo Jateng 2024).

Titik jalur tanpa tiang dinilai per simpul, bukan per ujung ruas. Ujung jalur (derajat 1) = ERROR. Belokan ≥ 30° = WARNING (pedoman konstruksi jaringan distribusi TR: sudut > 30° butuh tiang tambat). Belokan 15–30° = INFO. Sambungan dua ruas yang lurus tidak ditandai lagi, sehingga temuan palsu di setiap titik sudut garis hilang. Percabangan tanpa tiang = WARNING. Dasar teknis lengkap ada di DASAR_ATURAN.md di folder plugin.

Interaktif

Navigator QC: klik temuan, langsung ke lokasinya

  1. Setelah alat 1 selesai, panel Navigator QC Seranta terbuka di kanan (atau buka lewat Vector › Seranta › Navigator QC / ikon pin merah di toolbar).
  2. Temuan dikelompokkan per kategori dari alat 1 (folder QC), alat 3 (ALOKASI_FDT) dan alat 4 (folder QC_APD); angka di kurung = jumlah temuan. Warna: merah ERROR, oranye WARNING, abu-abu UNVERIFIED, kuning INFO.
  3. Klik satu temuan: peta zoom ke lokasinya, fitur dipilih (kuning) dan berkedip. Untuk rentang tiang, garis jalur antar kedua tiang yang ikut disorot.
  4. Berikutnya / Sebelumnya untuk menelusuri temuan satu per satu; centang Sembunyikan INFO; pilih filter tingkat (ERROR/WARNING/UNVERIFIED/INFO) dan review (belum/sudah direview); ketik di kotak cari (mis. H00172 atau NP6-145).
  5. Status review: pilih OPEN, VERIFIED (benar masalah), FALSE_POSITIVE (bukan masalah), APPROVED_EXCEPTION (pengecualian disetujui, wajib diisi alasan/bukti dan pemberi persetujuan) atau RESOLVED, isi catatan, lalu Simpan review. Status tersimpan di layer temuan dan tetap ada saat QC dijalankan ulang.
  6. Ekspor CSV menyimpan semua temuan beserta status review untuk reviewer/atasan. Temuan non-spasial (BOM, KMZ) tampil di grup tersendiri tanpa zoom.
  7. Arahkan kursor ke titik/garis di peta untuk melihat keterangan dan dasar aturannya (map tips).

Di ringkasan HTML, setiap titik temuan punya tautan 📍 lihat yang membuka lokasinya di OpenStreetMap (berguna di HP saat di lapangan).

Alat 3 · sebelum desain

Alokasi FDT & FAT (estimasi)

Menjawab: berapa FAT yang dibutuhkan cluster ini, FDT existing mana (≤ 1 km) yang masih bisa menampungnya, dan berapa FDT baru yang perlu dibuat.

  1. Jalankan alat 1 dulu untuk cluster tersebut (alat 3 memakai HP.shp dan POLE_PETA.gpkg di folder INPUT).
  2. Buka Vector › Seranta › 3. Alokasi FDT & FAT, pilih folder cluster (atau folder induk untuk banyak cluster), lalu Run.

FAT minimumHP ÷ 16, dibulatkan ke atas (16 HP = 2 splitter 1:8)Handbook FAT 8–16 HP; ODP-16

Standar Anda sendiri

Profil standar organisasi

Semua batas angka ada di profil JSON. Setiap angka punya nilai, dasar, sumber, dan status (disahkan atau parameter rekayasa).

Profil bawaan: APD_1X4 (default), APD_1X8, REGULASI_KETAT. Profil milik organisasi Anda (mis. dengan handbook internal) disimpan di luar folder plugin agar tidak tertimpa saat update. Seranta membaca profil tambahan dari:

  1. folder pada variabel lingkungan SERANTA_PROFILE_DIR,
  2. pengaturan QGIS seranta/profile_dir,
  3. <folder profil QGIS>\seranta\profiles\ (di Windows biasanya %APPDATA%\QGIS\QGIS3\profiles\default\seranta\profiles).
  4. paling mudah: folder Documents\Seranta\profiles di komputer Anda.

Profil dengan "default": true dipilih pertama. Profil dengan profile_id sama dengan profil bawaan menggantikannya. Salin salah satu file di folder profiles plugin sebagai contoh.

Bagaimana keandalannya diuji

  • 30 uji regresi otomatis (tests/test_qc_core.py dan tests/test_tool1_helpers.py) yang memetakan skenario UAT spesifikasi: HP not served, HP di luar Voronoi, dua ruas lurus tidak menjadi ujung palsu, ujung kabel tanpa FAT dan loop, dua FDT, FAT diklaim dua FDT, COLO/NEW Feeder–Distribusi, folder Feeder tidak ada (UNVERIFIED), status UNKNOWN, BOM tiang selisih dan satuan km, BOM tidak ada (UNVERIFIED), ikon X, warna kabel, profil, dan pembacaan .sdproj, ditambah penamaan cluster dan penggabungan FDT berkode sama. Semua lolos.
  • Dataset golden (tests/make_fixture_apd.py): desain APD sintetis di atas geometri strand nyata (190 HP, 27 tiang) dengan 15 cacat yang sengaja disisipkan. Alat 4 menemukan 15 dari 15 cacat.
  • Uji langsung di QGIS 3.40 pada tiga cluster uji dan satu proyek APD lengkap. Hasilnya dirangkum di bagian Yang baru.
  • Jarak diverifikasi terhadap jarak elipsoid Vincenty (selisih < 0,05 m).

Bantuan

Masalah umum

Zoom to Layer pada hasil Alokasi FDT tidak menampilkan apa-apa

Penyebabnya: layer ALOKASI_FDT dari run sebelumnya masih terbuka saat alat 3 dijalankan ulang, sehingga Windows mengunci file dan shapefile hanya tertimpa sebagian (extent di header tidak cocok dengan isinya). Sejak 3.3.0 alat 3 melepas layer lama sebelum menulis ulang. Untuk proyek lama, hapus grup "… ALOKASI FDT" dari panel Layers lalu jalankan ulang alat 3.

BAKP dilaporkan tidak ada padahal file-nya ada

Nama file BAKP sering hanya berupa nama jalan (mis. 2356732370_Jl. Syiah Kuala.pdf). Seranta 3.3.0 mengenalinya dari ID cluster di nama file dan PDF hasil scan, lalu menandainya UNVERIFIED (kandidat). Pastikan dokumennya memang BAKP, atau pilih file di isian Advanced File BAKP.

Banyak aturan alat 4 berstatus UNVERIFIED

Artinya data pendukung tidak diberikan: BOM, paket Feeder/Distribusi, layer Voronoi, atau atribut SUPID/MAXPPDIST (KMZ hasil copy-paste kadang kehilangan atribut). Pakai export shp desain otomatis langsung dan isi BOM serta paket Feeder agar aturan tersebut bisa diputuskan.

"Tidak ada file HPDB di folder ini maupun di subfoldernya"

Nama file harus mengandung kata HPDB dan berformat .xlsx, .xls, atau .csv. Tutup file di aplikasi spreadsheet bila sedang terbuka.

Funnel tidak muncul (layer FUNNEL_SEKITAR tidak ada, standar 2 & 5 bertanda --)

Lihat kartu Data referensi di ringkasan QC, lalu cocokkan pesannya:

  • "Data referensi tidak ada": isian 2 kosong dan folder referensi tidak ditemukan. Salin folder referensi tim ke komputer ini, lalu pilih di isian 2. Plugin dari ZIP maupun Plugin Manager tidak membawa data ini.
  • "Folder referensi yang diingat tidak ada di komputer ini": pengaturan dari komputer atau path lama. Pilih ulang isian 2.
  • Funnel bertanda ✗: tidak ada file yang namanya mengandung kata FUNNEL (.kmz/.kml) di folder itu atau subfoldernya. Ganti nama file atau tambahkan file Funnel.
  • "File Funnel tidak mencakup lokasi cluster (0 poligon dalam 1 km)": file Funnel yang ada untuk kota lain (mis. hanya EXISTING CITY, cluster di NEW CITY). Tambahkan file Funnel kota tersebut.
  • "File Funnel tidak bisa dibaca, mungkin rusak": unduhan terpotong. Unduh ulang file Funnel.
  • "Layer FUNNEL_SEKITAR gagal ditulis": folder hasil tidak bisa ditulis atau GDAL menolak. Cek boundary tetap berjalan; Seranta otomatis mencoba Shapefile FUNNEL_SEKITAR.shp.
QC_TEMUAN kosong / tidak muncul

Diperbaiki di v3.1.3: file temuan kini ditulis langsung oleh Seranta. Bila masih kosong, lihat tabel Temuan per jenis di ringkasan QC: "Tidak ada titik temuan" berarti cluster memang bersih. Pastikan memakai v3.1.3 (Vector › Seranta › Tentang) lalu jalankan ulang.

Standar bertanda --

Data pembanding belum ada. Isi Folder data referensi dengan Funnel, Design Lite, dan HPDB attributes.

Kode hasil berubah menjadi lebih pendek

Path folder sangat panjang. Seranta memendekkan kode agar tidak melebihi batas 260 karakter Windows. Hasil tetap lengkap.

Run pertama lambat

Seranta membangun cache dari file referensi besar (Funnel, Design Lite). Run berikutnya jauh lebih cepat.

"Integritas: DIMODIFIKASI" di laporan

File plugin berbeda dari rilis resmi. Pasang ulang dari Plugin Manager agar hasil QC dapat dipercaya.

Ringkasan QC tidak terbuka

Buka manual file <KODE>_RINGKASAN_QC.html di folder INPUT_<KODE>, atau pastikan isian 5 dicentang.
